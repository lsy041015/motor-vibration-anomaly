Test 성능 (윈도우 단위, 임계값 )
임계값 실험
임계값은 Training CV로 정한 값임. 슬라이더는 Test에서의 변화를 보여주는 참고용이고, 모델 선택에는 쓰지 않음.

혼동행렬 (행 = 실제, 열 = 판정)

정상 판정불량 판정
실제 정상
실제 불량

모터별 정답 비율 (80% 미만 = 진한 빨강)

이상점수 분포 (점선 = 임계값, 오른쪽이면 불량 판정)

후보 모델 비교 (Training CV 기준 정렬, 초록 행 = 선택된 모델). Test F1은 기록만 함.

선택 규칙: cv F1 1위와 0.002 이내인 후보는 spd F1(회전속도 그룹 제외 CV)로 순위를 정함. cv = 모터 단위 5-fold, flt = 불량 유형 제외 CV.

모터 (정답 비율)

정상 판정불량 판정

모터의 모든 윈도우 이상점수 (점 클릭 = 그 윈도우 선택, 점선 = 임계값)

파일

추론 과정 (선택 윈도우)

1. 파형 (256 샘플 윈도우, 클릭 = 윈도우 선택)

2. FFT (초록 점선 = f0 배수, 빨간 띠 = 불량 대역)

3. 특징값: Training 정상 평균에서 떨어진 정도 (z, |z|>3 빨강)

4. 검출기별 이상순위 → 평균 → 임계값 비교

이상순위 = Training 정상 윈도우 중 이 윈도우보다 덜 이상한 비율 (0~1). 세 검출기의 평균이 이상점수임.
